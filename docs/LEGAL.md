## Dependency license policy

- **Allowed:** MIT, Apache-2.0 (incl. LLVM exception), BSD-2-Clause, BSD-3-Clause, ISC, Zlib,
  Unlicense, 0BSD, CC0-1.0, Unicode-3.0. Enforced for Rust by `cargo deny check licenses`
  (`deny.toml`) in CI.
- **Not allowed:** GPL, LGPL, AGPL, MPL, SSPL, BUSL, OFL, CC-BY-SA/NC and proprietary or
  "source available" licenses, and anything with field-of-use restrictions.
- **Exceptions (build-time only):** `cssparser`, `cssparser-macros`, `selectors`, `dtoa-short`
  (MPL-2.0) are used by Tauri's code generator inside the compiler and are not linked into
  `frostcap.exe` (verified with `cargo tree -e normal,no-proc-macro -i <crate>`). They are
  named one by one in `deny.toml`; re-verify before each release.
- **Replaced:** the MPL-2.0 `option-ext` crate (runtime dependency of `dirs-sys`) is replaced
  by `crates/option-ext-shim`, an independently written MIT crate.
- **npm:** only permissively licensed packages are bundled into the UI. `caniuse-lite`
  (CC-BY-4.0) is a build-tool dependency and is not distributed. npm licenses are not yet
  enforced automatically; review `THIRD_PARTY_LICENSES.md` sections 4-5 in pull requests that
  change `ui/package-lock.json`.
- **Attribution:** [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md) is generated by
  `scripts/gen-third-party.mjs`, checked for freshness in CI, and should ship with every
  release (it is attached to the repository; consider also adding it to the installer).

## WebView2

Frostcap's UI runs in the Microsoft Edge WebView2 Runtime, a Microsoft component that is
part of Windows 11 and installed on most Windows 10 systems. Frostcap does **not** include
the runtime in its repository or in the portable exe. The NSIS installer built by Tauri can
run Microsoft's small WebView2 bootstrapper, which downloads the Evergreen runtime from
Microsoft when it is missing.

Microsoft permits distributing the WebView2 Runtime and bootstrapper with applications under
its WebView2 distribution terms (see the "Distribute your app and the WebView2 Runtime" page
of the Microsoft Edge WebView2 documentation and the license terms shown there). The
maintainers have **not** reviewed those terms in detail for this project. Before shipping an
installer that embeds or downloads WebView2, read the current terms and confirm they fit.
Using a fixed-version runtime bundled inside Frostcap is not planned.

## H.264, AAC and Media Foundation

- Frostcap does not include any video or audio codec implementation. It calls the **Media
  Foundation** encoders and decoders that ship with Windows (and hardware encoders provided
  by GPU drivers). Frostcap does not ship FFmpeg, x264, openh264 or similar libraries.
- H.264/AVC and AAC are covered by patents that are licensed through patent pools (for
  example Via Licensing Alliance, formerly MPEG LA, for AVC). The maintainers' understanding
  is that the codec licensing for the encoders and decoders inside Windows is handled by
  Microsoft and the hardware vendors, and that an application calling the OS codec does not
  itself ship a codec. **Whether any obligation applies to a particular distribution or use
  of the resulting video (for example commercial content distribution) has not been
  verified.** If that matters to you, get advice.
- **Windows N and KN editions** ship without Media Foundation's media features. Users must
  install the free **Media Feature Pack** from Microsoft (Settings -> Apps -> Optional
  features on recent versions) or recording and export will fail.
- Planned GIF export uses the `gif` crate (MIT/Apache-2.0); GIF's LZW patents have expired.

## Name and logo

**Decision (maintainer, may be revised):** the Frostcap name and the logo in `assets/brand/`
are released under the same MIT license as the code. The project makes no separate trademark
claim and has no trademark policy; forks may reuse the logo. If the maintainer later decides to
reserve the name and logo (for example to ask forks to rename), this section and the README
must be updated together, and a change would apply only to future releases.

The maintainer should still confirm that the logo artwork (`logo-source.webp`) was created by
or for the project and that the project has the right to license it.

Third-party names (Windows, Microsoft Edge, WebView2, H.264 and others) are trademarks of
their owners and are used only to describe compatibility. Frostcap is not affiliated with or
endorsed by Microsoft.

## Privacy and recording law

Frostcap can record screens, audio and keystrokes. Recording other people (for example in a
call) may require their consent depending on where you are. Users are responsible for how
they use it. See [PRIVACY.md](PRIVACY.md) for what the app records.
